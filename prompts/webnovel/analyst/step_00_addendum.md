# Analyst — STEP 0 웹소설 추가 지침 (Addendum)

`prompts/analyst/step_00_critique.md` 를 기본 지침으로 따르되, 이 문서의 내용으로 **대체·추가**한다.

## 대체 규칙

기본 지침의 "장편 영화 시나리오 전환" 관점을 **200화 연재 웹소설 확장** 관점으로 바꿔 읽는다.

| 기본 지침 항목 | 웹소설 모드에서의 해석 |
|---------------|----------------------|
| 3막 구조 명확성 | 시리즈 전체 3막 + 아크 분할 가능성 |
| 영상적 묘사 수준 | **적용 제외** — 웹소설은 내면 서술을 허용한다. 대신 "설명 과다(정보 덤프)" 여부만 본다 |
| 이미지 시스템 | **적용 제외** — STEP 3 설정집·떡밥 원장이 대체 |
| 원작→장편 전환 이슈 | 시놉시스→200화 확장 이슈 (분량 부족, 반복 위험) |
| 3.2 미드포인트 장르 전복 | 시리즈 중반(90~110화) 판 전환 + 아크별 전(轉) |
| 3.6 원작 형식 → 장편 호흡 | 원작 형식 → 회차 호흡 (회차당 1~2사건, 매 회차 절단) |

## 추가 분석: 연재 적합성 (출력 섹션 3.8로 추가)

다음 6개 항목을 점검하고, 각각 현황과 보완 방향을 적는다.

1. **갈등 동력의 총량** — 시놉시스의 갈등만으로 200화(약 100만 자)를 채울 수 있는가. 부족하면 확장 가능한 축(세력, 과거사, 조연 서브플롯, 세계관 층위)을 구조 수준에서 제시
2. **성장·상승 사다리** — 주인공의 목표·능력·지위가 단계적으로 올라갈 계단이 몇 단 있는가 (아크 수의 근거가 됨)
3. **반복 위험** — 같은 패턴(위기→각성→승리)이 무한 반복될 위험. 아크마다 갈등 유형을 바꿀 수 있는가
4. **1화 훅 후보** — 시놉시스에서 1화 첫 장면으로 쓸 수 있는 가장 강한 상황 2~3개
5. **유료 전환 후보 사건** — `paywall_episode` 직전에 배치할 만한 반전·클라이맥스 후보 2~3개 (0이면 생략)
6. **웹소설 장치 적합성** — 시놉시스 설정이 5대 장치(수치 성장·사이다·유머·경쟁·관계, `webnovel/analyst/system.md`) 중 무엇을 자연스럽게 지원하는가. 장치가 비어 있으면 "주제·반전 중심, 장치 부족"으로 명시하고 설정에서 장치로 전환할 수 있는 요소를 제시

## 추가 품질 기준

- [ ] 연재 적합성 6개 항목을 모두 점검했는가 (웹소설 장치 포함)
- [ ] 200화 확장 시 부족한 갈등 동력을 "얼마나"(대략적 회차 규모) 부족한지 수치로 제시했는가
- [ ] 영상 묘사 관련 기준을 웹소설에 잘못 적용하지 않았는가
