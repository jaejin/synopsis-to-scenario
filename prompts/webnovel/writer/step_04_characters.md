# Writer — STEP 4: 캐릭터 설계

## 입력 컨텍스트

- `projects/{name}/input/` — 원본 시놉시스
- `projects/{name}/output/step_00_critique.md` — 사전 분석 (특히 3.4 단면적 인물)
- `projects/{name}/output/step_01_series_structure.md` — 시리즈·아크 구조
- `projects/{name}/output/step_02_arc_beats.md` — 아크별 비트
- (STEP 3과 병행 시) `projects/{name}/output/step_03_setting_bible.md`

## 작업 지시

200화 동안 독자가 따라갈 인물을 설계하라. 영화와 달리 인물은 **수십 화에 걸쳐 조금씩 변한다**. 변화를 아크에 배분하는 것이 핵심이다.

### 주인공

| 항목 | 내용 |
|------|------|
| 이름·나이·외형 식별자 | 외형 식별자 2~3개 (독자가 떠올릴 이미지) |
| 말투 샘플 | 대사 3줄 (평상시 / 분노 / 약해졌을 때) |
| 겉목표 / 속욕구 | 겉으로 좇는 것 vs 실제로 필요한 것 (유니티 아크) |
| 결함 | 200화 동안 극복해 가는 결함 1개 |
| 차별점 | 이 장르의 다른 주인공과 다른 점 (능력·처지·태도) |
| 첫 등장 | 1화에서 이 인물의 본질을 드러내는 행동 1개 (Hauge) |
| **성장 곡선** | 아크별로 무엇을 얻고/잃고/깨닫는지 표로 |

### 주요 조연 (4~8명)

주인공과 같은 항목에 더해:
- **주인공과의 관계 변화** — 아크별 관계 상태 (적 → 경쟁자 → 동료 등)
- **자기만의 목표** — 주인공을 돕기만 하는 인물은 없다
- **퇴장 계획** — 몇 화에서 퇴장/비중 축소하는지 (장기 연재는 인물이 쌓이면 산만해진다)

### 적대자 (아크별 + 최종)

- 아크마다 적대자 1명 이상, 시리즈 최종 적대자 1명
- 적대자의 논리 — 그 입장에서는 옳은 이유 (단면적 악 금지)
- 최종 적대자가 **처음 암시되는 회차**와 **정체가 드러나는 회차** (떡밥 원장 ID와 연결)

### 호칭·말투 표

인물 A가 인물 B를 부르는 호칭을 표로 정리한다. 관계 변화에 따라 호칭이 바뀌면 바뀌는 회차도 적는다. 200화 동안 가장 자주 틀리는 부분이다.

| 부르는 사람 \ 불리는 사람 | 주인공 | 조연1 | ... |
|---|---|---|---|

## 품질 기준

- [ ] 주인공 성장 곡선이 모든 아크에 배분돼 있는가 (변화 없는 아크가 없는가)
- [ ] 조연마다 자기 목표와 퇴장/비중 계획이 있는가
- [ ] 모든 적대자에게 자기 논리가 있는가
- [ ] 호칭·말투 표가 주요 인물 전원을 포함하는가
