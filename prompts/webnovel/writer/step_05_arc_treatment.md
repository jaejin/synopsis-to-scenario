## 작업 지시

아크마다 **산문 트리트먼트**를 쓴다. STEP 2의 비트를 이야기로 풀어, 이 아크가 "읽히는 이야기"인지 확인하는 단계다.

### 아크별 분량

- 아크당 **2,000~4,000자** (공백 제외). 8~10개 아크면 전체 약 2~4만 자
- 한 번에 다 쓰기 어려우면 아크 3~4개씩 나눠 쓰고 같은 파일에 이어 붙인다

### 아크 트리트먼트에 담을 것

1. **아크 로그라인** — 한 문장
2. **서사** — 기·승·전·결을 현재형 산문으로. 인물의 선택과 그 대가가 보이게
3. **감정선** — 이 아크에서 주인공의 감정이 어디서 어디로 이동하는가
4. **서브플롯** — 조연 서브플롯 1~2개와 메인 플롯에 합류하는 지점
5. **떡밥** — 이 아크에서 심는/회수하는 떡밥 ID
6. **다음 아크 연결** — 아크 마지막 장면과, 그것이 다음 아크 첫 장면에 어떻게 이어지는가

### 원본 보존 원칙

- STEP 0 강점(섹션 2)으로 지목된 원작 요소는 어느 아크에 들어갔는지 표시한다
- 원작 시놉시스의 사건이 200화로 늘어나며 사라지지 않았는지 확인한다

## 출력 형식

```markdown
# STEP 5: 아크 트리트먼트

## 아크 1: {제목} (1~XX화)
**로그라인**: ...

(산문)

- 감정선: ... → ...
- 서브플롯: ...
- 떡밥: 심기 F-001, F-004 / 회수 -
- 다음 아크 연결: ...

## 아크 2 ...

## 원작 요소 반영표
| 원작 요소 (STEP 0 강점) | 반영 아크 |
```

## 품질 기준

- [ ] 모든 아크가 트리트먼트로 작성됐는가
- [ ] 아크마다 주인공의 능동적 선택이 서사 안에 보이는가
- [ ] 떡밥 원장의 계획 회차와 트리트먼트의 배치가 일치하는가
- [ ] 원작 강점 요소가 모두 어느 아크엔가 반영됐는가
