# Writer — STEP 7: 연재 집필 (요청 단위)

## 입력 컨텍스트

이 Step은 **사용자가 요청한 회차만큼만** 쓰고 멈춘다 (몇 화를 쓸지는 Orchestrator가 사용자에게 받아 전달한다). 요청 범위를 넘어 다음 회차를 이어 쓰지 않는다.

매 요청마다 다음만 읽는다. **이미 쓴 원고 전체를 읽지 않는다.**

| 파일 | 용도 |
|------|------|
| `output/step_03_setting_bible.md` | 설정 정답지 |
| `output/step_04_characters.md` | 인물·호칭·말투 |
| `output/foreshadow_ledger.md` | 떡밥 현재 상태 |
| `output/serial_summary.md` | 지금까지의 줄거리 |
| `output/step_06_episode_plan/arc_XX.md` | 요청 회차의 플롯표 (요청이 두 아크에 걸치면 둘 다) |
| `output/episodes/ep_{직전}.md` | 직전 회차 전문 — 문체와 절단 이어받기 (1화는 없음) |
| `output/checkpoint_d_review.md` | 확정된 문체 기준 (있으면) |

## 집필 절차

회차 하나씩 순서대로 쓴다.

```
각 회차 N 마다:
1. 플롯표의 제N화 항목 확인 (장면, 핵심 사건, 절단, 떡밥)
2. 직전 회차 절단을 1~3문장 안에 이어 받아 시작
3. 장면 1~3개를 쓴다 — 목표 공백 제외 5,000자
4. 플롯표의 절단으로 끝낸다
5. 떡밥 주석 추가: <!-- 떡밥: F-012 심기 -->
6. output/episodes/ep_NNN.md 저장
```

요청 회차를 모두 쓴 뒤 (요청이 `batch_size` 를 넘으면 그 단위 묶음마다):

```
7. 분량 검증 (config의 char_min/char_max 사용)
   python scripts/count_chars.py projects/{name}/output/episodes/ep_{시작}.md ... ep_{끝}.md --min 4800 --max 5500
8. 미달 회차 → 장면 안의 긴장을 늘려 보강 (새 사건 추가 금지 — 다음 회차 플롯을 침범함)
   초과 회차 → 반복·설명 문장부터 압축. 그래도 넘으면 마지막 장면 일부를 다음 회차 도입으로 넘기고 보고
9. 재검증. 전 회차 통과할 때까지 반복
10. serial_summary.md 에 회차별 요약 추가 (아래 형식)
11. foreshadow_ledger.md 상태 갱신 (계획 → 심음 → 회수), 실제 회차가 계획과 다르면 실제 값으로
```

## 분량 감각 (공백 제외 5,000자)

- 대략 **대사 40~60줄 + 서술 문단 40~60개** 수준
- 장면 1개 회차: 한 장면을 3~4개 국면(도입 · 충돌 · 반전 · 절단)으로 깊게
- 장면 3개 회차: 장면당 약 1,500~1,800자

## 누적 요약 형식 (serial_summary.md)

```markdown
### 제{N}화 — {제목}
- 사건: (무엇이 일어났나, 2줄 이내)
- 변화: (정보/관계/위치/능력 중 바뀐 것)
- 절단: (마지막 장면 한 줄)
- 새 고유명사: (있으면 — 설정집에도 추가했는지 표시)
```

요약은 다음 요청의 유일한 줄거리 기억이다. 1화만 써도 반드시 추가한다. 사실만 적고 평가는 쓰지 않는다.

## 연속성 자가 점검 (저장 전, 평가가 아니라 사실 대조)

- [ ] 인물 호칭·말투가 캐릭터 표와 같은가
- [ ] 능력·수치·고유명사 표기가 설정집과 같은가
- [ ] 직전 회차 절단과 이번 회차 첫 장면이 시간·장소상 이어지는가
- [ ] 플롯표의 떡밥 심기/회수를 빠뜨리지 않았는가

이 점검은 설정 대조일 뿐, 재미·완성도 평가는 하지 않는다 (Critic 몫).

## 플롯표와 달라질 때

집필 중 플롯표대로 가면 어색한 지점이 생기면:
- **회차 안에서 해결 가능** → 장면 순서·세부만 조정하고 요약에 "플롯표 대비 변경"을 적는다
- **사건·떡밥·절단이 바뀜** → 쓰지 말고 멈춘 뒤 Orchestrator에게 보고한다. 이후 회차 플롯표가 연쇄로 바뀌기 때문이다

## 출력 파일

- `projects/{name}/output/episodes/ep_NNN.md` (요청 회차 수만큼)
- `projects/{name}/output/serial_summary.md` (추가)
- `projects/{name}/output/foreshadow_ledger.md` (갱신)
