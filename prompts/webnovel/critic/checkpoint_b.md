# Critic — 체크포인트 B: 설정·캐릭터 확정 리뷰 (웹소설)

## 입력 컨텍스트

- `projects/{name}/output/step_01_series_structure.md`
- `projects/{name}/output/step_02_arc_beats.md`
- `projects/{name}/output/step_03_setting_bible.md` — 설정집
- `projects/{name}/output/foreshadow_ledger.md` — 떡밥 원장
- `projects/{name}/output/step_04_characters.md` — 캐릭터

## 중요도

> 설정집·떡밥 원장·캐릭터 표는 200화 집필 동안 유일한 기억 장치다.
> 여기서 모호하거나 빠진 항목은 이후 설정 충돌로 돌아온다.

## 체크리스트 (pass 기준)

### 1. 설정 완결성
- [ ] 설정집 7개 섹션이 모두 채워짐
- [ ] 능력·힘 체계에 대가와 한계가 있음 (해당 장르일 때)
- [ ] 용어집 표기가 하나로 통일됨 (같은 대상의 표기 흔들림 없음)

### 2. 설정–구조 정합
- [ ] STEP 1 아크별 무대·세력이 설정집에 모두 등록됨
- [ ] 세계관 "불가능한 것" 목록과 STEP 2 비트가 충돌하지 않음

### 3. 떡밥 원장
- [ ] 30개 이상, 장기 떡밥(간격 50화 이상) 5개 이상
- [ ] 아크별 전(轉)·시리즈 미드포인트·최종 결판에 대응 떡밥 ID 존재
- [ ] 모든 떡밥에 심는·회수 회차(계획)와 위장 방식이 있음

### 4. 캐릭터 입체성
- [ ] 주인공 성장 곡선이 모든 아크에 배분됨
- [ ] 조연 전원이 자기 목표와 비중/퇴장 계획을 가짐
- [ ] 적대자 전원이 자기 논리를 가짐

### 5. 연속성 장치
- [ ] 호칭·말투 표가 주요 인물 전원을 포함
- [ ] 인물별 말투 샘플이 서로 구별됨 (이름을 가리면 누가 말했는지 알 수 있는가)

## 평가 로직

- 5개 모두 ✅ → `pass`
- 1~2개 ⚠️ → `conditional_pass`
- 3개 이상 ⚠️ 또는 1개 이상 ❌ → `rework_needed`
