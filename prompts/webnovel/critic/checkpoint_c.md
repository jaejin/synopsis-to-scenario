# Critic — 체크포인트 C: 집필 전 최종 리뷰 (웹소설)

## 입력 컨텍스트

- `projects/{name}/config.yaml` — `web_novel` 블록
- `projects/{name}/output/step_02_arc_beats.md`
- `projects/{name}/output/step_05_arc_treatment.md` — 아크 트리트먼트
- `projects/{name}/output/step_06_episode_plan/arc_*.md` — 회차 플롯표 전부
- `projects/{name}/output/foreshadow_ledger.md`
- `projects/{name}/output/step_00_critique.md` — 원작 강점 확인용

플롯표가 커서 한 번에 읽기 어려우면 아크 파일 단위로 점검한 뒤 결과를 합친다.

## 중요도

> 이 체크포인트를 통과하면 200화 집필이 시작된다.
> 집필 도중 플롯표를 고치면 이미 쓴 회차와 충돌하므로, 여기서 최대한 잡는다.

## 체크리스트 (pass 기준)

### 1. 회차 완결성
- [ ] 1~`total_episodes` 화가 빠짐없이, 중복 없이 존재
- [ ] 모든 회차에 핵심 사건·절단·긴장도가 있음
- [ ] 사건 3개 이상 또는 장면 4개 이상인 회차 없음 (5,000자에 담기 어려움)

### 2. 트리트먼트 반영
- [ ] 트리트먼트의 장면이 플롯표에 모두 반영됨
- [ ] 원작 강점 요소(STEP 0 섹션 2)가 모두 특정 회차에 배치됨

### 3. 절단·리듬
- [ ] 같은 절단 유형 3화 연속 없음
- [ ] 보상 간격 5화 초과, 고구마 3화 초과 없음
- [ ] 공회전 회차(핵심 사건이 "대화한다", "이동한다" 수준) 없음

### 4. 유료 전환 구간 (`paywall_episode` > 0)
- [ ] `paywall_episode-3 ~ paywall_episode` 긴장도 8 이상
- [ ] 전환 직전 회차 절단이 폭로 또는 위기
- [ ] 전환 회차 첫 장면이 직전 절단에 대한 보상을 줌

### 5. 떡밥 정합
- [ ] 떡밥 원장의 계획 회차와 플롯표의 심기·회수가 모두 일치
- [ ] 심기 전에 회수되는 떡밥 없음
- [ ] 회수 계획이 없는 떡밥 없음 (의도된 후속작 떡밥은 명시)

## 평가 로직

- 5개 모두 ✅ → `pass`
- 1~2개 ⚠️ → `conditional_pass`
- 3개 이상 ⚠️ 또는 1개 이상 ❌ → `rework_needed`
