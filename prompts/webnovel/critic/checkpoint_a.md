# Critic — 체크포인트 A: 시리즈 구조 확정 리뷰 (웹소설)

## 입력 컨텍스트

- `projects/{name}/config.yaml` — `web_novel` 블록
- `projects/{name}/output/step_00_critique.md` — 사전 분석 (3.8 연재 적합성 포함)
- `projects/{name}/output/step_01_series_structure.md` — 시리즈·아크 구조
- `projects/{name}/output/step_02_arc_beats.md` — 아크별 비트

## 중요도

> 이 체크포인트 이후로는 아크 구조를 바꾸기 어렵다.
> 200화의 모든 회차가 이 뼈대 위에 배치된다.

## 체크리스트 (pass 기준)

### 1. 회차 정합성
- [ ] 아크 회차 범위의 합 = `total_episodes`, 누락·중복 없음
- [ ] 아크 수 8~10개, 아크당 15~30화
- 위반 시: 문제 아크와 범위 명시

### 2. 아크 다양성
- [ ] 인접 아크의 갈등 유형이 겹치지 않음
- [ ] 아크가 진행될수록 판(무대·적·걸린 것)이 커짐
- 위반 시: 반복되는 아크 쌍 명시

### 3. 초반·유료 전환 설계
- [ ] 1화 오프닝 훅과 5화 이내 목표 확정이 회차 번호로 있음
- [ ] 장르의 약속이 무료 구간 안에서 한 번 이상 완결됨
- [ ] 첫 아크가 `paywall_episode` ±3화 안에서 끝나고, 직전 3화에 클라이맥스/반전 배치 (`paywall_episode` = 0 이면 생략하고 ✅)
- 위반 시: 현재 위치와 문제

### 4. 리듬
- [ ] 보상 간격 5화 초과 구간 없음
- [ ] 고구마 3화 초과 구간 없음 (사유 있으면 ⚠️)
- [ ] 긴장도 8 이상이 20화 넘게 이어지는 구간 없음
- [ ] 시리즈 미드포인트가 45~55% 구간

### 5. 주인공 능동성
- [ ] 아크마다 능동적 선택 지점 2곳 이상

### 6. STEP 0 보완점 반영
- [ ] 연재 적합성(3.8)에서 지적한 동력 부족·반복 위험이 구조로 해결됨

### 7. 웹소설 장치
- [ ] 1화 장치 획득 · 5화 이내 첫 사이다 · 10화 이내 첫 수치 성장
- [ ] 쓰기로 한 장치가 아크마다 작동함 (장치 없는 아크 없음)
- [ ] 장치가 주제·결말과 연결된 지점이 1곳 이상
- 위반 시: "주제는 선명하나 웹소설로 읽히지 않는" 구간을 회차로 명시

## 평가 로직

- 7개 모두 ✅ → `pass`
- 1~2개 ⚠️ → `conditional_pass`
- 3개 이상 ⚠️ 또는 1개 이상 ❌ → `rework_needed`
